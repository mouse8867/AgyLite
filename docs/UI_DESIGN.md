# AgyLite v2 UI 设计规范（液态玻璃落地版）

来源：Xi 提供的《高级感 UI 资源地图 · 2026》（UI.md），2026-11-24 定为 AgyLite v2 的界面与质感方案。
原则：**借设计语言，不借代码**。资源地图里的仓库几乎全是 Web/React/TS 技术栈，Rust+egui 一个都不能直接用；落地的是它的视觉语言、配色数值和交互模式，全部用 egui 自绘实现。

## 一、从资源地图里取什么、不取什么

取（与一个桌面小工具相关的）：
- 0.3 节「玻璃风底座」：背景渐变、玻璃卡片参数、描边/高光/圆角/阴影、强调色、字体层级——这是质感的根。
- 01 液态高亮块（Liquid Pill）：用于顶部分段切换（状态 / 检测 / 设置）和“启动后行为”三选一，胶囊滑动 + 拉长 + 弹性回弹。
- 02 光跟着鼠标走（弱化版）：只给主启动按钮/状态卡做悬停径向光斑 + 边缘提亮；**不做 3D 倾斜**，桌面工具要稳重。
- 03 模块就地放大（弱化版）：环境检测的某一项点击后就地展开详情与修复提示，其余项收起，不跳新窗口。

不取：
- 04 水滴分裂筛选、05 命令面板、06 玻璃停靠栏：分别是筛选器、⌘K 搜索和 Dock 的交互，AgyLite 没有对应场景，硬塞只会臃肿。托盘菜单保持系统原生。
- 真实折射/色散 shader（quickLiquid、liquid-glass-react 等）：WebGL 方案，egui 里复刻成本高且吃资源，与“托盘常驻 ≤20MB、CPU 约 0”的硬指标冲突。用静态渐变 + 半透明层叠伪造玻璃感，小窗口尺寸下观感足够接近。

## 二、AgyLite 专属设计令牌（由底座提示词改配）

底座原配色是暖桃晚霞（#E4C0A6 / #D4B8AC / #EBD7CC），照搬会像生活类 App。AgyLite 是开发者工具，保留玻璃结构，色调改冷：

- 背景渐变（窗口底）：左上 #2E3A4A（深蓝灰）→ 中段 #4A5A6E → 底部 #7A8CA3，叠一道白色 6% 透明度的斜向光弧。深色玻璃与 Antigravity 的深色界面也更搭。
- 玻璃卡片：白色 10%–16% 半透明填充（深色底上的等效磨砂感），1px 白色 28% 描边，顶部内侧 1px 白色 40% 高光线，圆角 18px，阴影为大半径低透明黑色柔影。
- 主按钮（启动）：铜橙强调色沿用底座的 #B66D44 → #E7A471 渐变（全界面唯一的暖色，负责“贵”和聚焦），白色文字，圆角 14px 胶囊形；悬停时光斑跟随（见一·02）。
- 状态色：正常 #7BC47F，警告 #E7A471，错误 #E06C5F；只用于小圆点和图标，不大面积铺色。
- 深色压舱卡：一张近黑卡（#1B1B19，顶部铜色光晕）用于“当前状态”主卡，压住整个浅玻璃画面——照底座原法。
- 字体：中文用微软雅黑（运行时加载系统字体，与 exe 不内嵌 CJK 全集的策略一致），拉丁/数字用 Inter 或系统 Segoe UI；数字用等宽数字特性。标题 20px，卡片标题 14px，正文 13px，注释 12px。
- 间距：窗口内边距 20px，卡片间距 12px，统一 4 的倍数。

## 三、主窗口结构（单窗，三段）

1. 顶栏：自有图标 + “AgyLite” + 版本号小字；右侧液态胶囊分段：状态 / 检测 / 设置。
2. 状态页（默认）：深色状态主卡（Antigravity 路径与版本、代理端口、TUN 状态，一行一状态点）+ 玻璃卡“环境检测摘要”（只显示异常项，全过时显示一行“环境正常”）+ 底部大启动按钮 + 启动后去向提示文案。
3. 检测页：自检清单就地展开（见一·03），每项 ✅/⚠️/❌ + 修复提示。
4. 设置页：开机自启开关、启动后行为（液态胶囊三选一：收进托盘 / 自动关闭 / 保持窗口）、清理残留开关、高级折叠区（路径手动选择、端口手动输入）、关于入口（邮箱 mouse8867@gmail.com、版本、仓库链接、许可证、免责声明）。

## 四、动效与性能纪律

- 动效只在交互时发生：胶囊滑动约 220ms 弹性、光斑跟随、展开收起约 180ms；窗口静止和托盘常驻时零动画、零重绘循环（egui 切到被动重绘），守住资源硬指标。
- 玻璃感全部用静态绘制（渐变网格 + 半透明层 + 描边高光 + 柔影），不跑持续 shader、不截屏做真实模糊。
- 125%/150% 缩放下用 egui 的 DPI 缩放统一处理，验收仍按规格主文档的清单执行。

## 五、图标

沿用主规格方向（深色底 + 轨道环 + 中心点），按本规范配色重绘：深蓝灰底、白色半透明轨道环、铜橙中心点——与主按钮同色呼应。.ico 多尺寸 16/32/48/256，托盘图标用单色简化版。
